# TONLY Predictive Maintenance v1.0.0

## Architecture changes
- Removed Supabase database/auth dependencies and separate Render deployment.
- Added Neon PostgreSQL schema and parameterized server-side access.
- Added single-planner authentication using scrypt password verification and signed HttpOnly session cookies.
- Moved Random Forest/XGBoost computation into a Python Vercel Function (`api/ml_compute.py`) within the same Vercel project. No Vercel Services configuration or service bindings are required.
- Preserved the existing TONLY dashboard, source-data preview, quality checks, PM rules, model comparison, and provisional forecast flow.
